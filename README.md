# 🚢 Titanic Survival Prediction

A machine learning classification project based on the **Kaggle Titanic: Machine Learning from Disaster** competition. The goal is to predict whether a passenger survived the Titanic disaster using demographic and passenger-related features.

## 🎯 Objective

Build an end-to-end ML classification pipeline to predict passenger survival and identify the factors that influenced survival.

## 📊 Dataset

* **Source:** Kaggle — Titanic: Machine Learning from Disaster
* **Target:** `Survived`
* **Files:** `train.csv`, `test.csv`
* **Problem Type:** Supervised Learning → Classification

## 🔧 Workflow

1. Exploratory Data Analysis (EDA)
2. Missing Value Treatment
3. Feature Engineering
4. Categorical Encoding
5. Feature Selection
6. Train/Validation Split
7. Model Training
8. Model Evaluation
9. Cross-Validation
10. Prediction & Submission

## 🤖 Model

**Scikit-learn Classification Model**

* Handles binary classification effectively
* Uses engineered passenger features
* Evaluated using **Accuracy** and classification metrics

## 📈 Result

**Accuracy IN System : 80%**
**Accuracy IN Kaggle : 74%**

The model demonstrates solid predictive performance and provides an end-to-end example of solving a real-world binary classification problem.
